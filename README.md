📚 StudyFlow - Smart Study Planner
📖 About the Project

StudyFlow is a responsive study planner web app that helps students organize their learning in one place. Users can add study tasks with a subject, priority and due date, then search, filter, complete or delete them. A live dashboard shows total, completed and pending tasks along with an overall progress percentage, so students can see how much they have achieved.

All tasks are saved in the browser, so the data stays even after refreshing the page.

This project was developed as Task 3 of my internship at Skill Nexis.

✨ Features
Add tasks with name, subject, priority (Low / Medium / High) and due date
Search by task name or subject
Filter by status (pending / completed) or priority
Mark tasks as complete or delete them
Live stats: total, completed and pending tasks
Progress bar with motivational messages
"Today's Focus" card that updates automatically
Toast notifications for instant feedback
Fully responsive on desktop, tablet and mobile
